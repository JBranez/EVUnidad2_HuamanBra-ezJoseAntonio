# Relación con la rúbrica

- Contenido, funcionalidades y calidad del código: servicios, médicos, reseñas, promociones y formulario implementados; responsabilidades separadas.
- Angular: componentes standalone, interfaces TypeScript y `HospitalService`.
- Signals: `signal()` para el formulario, alerta y solicitudes almacenadas; los datos registrados se muestran en pantalla.
- Diseño visual: Bootstrap 5 para grillas, formularios, botones, navbar y responsive; CSS propio para identidad visual.
- Alertas: Bootstrap alert con mensajes de éxito y validación y botón de cierre.
- Git: la rúbrica exige repositorio y commits; esta carpeta incluye comandos de ejemplo en README.
- Sustentación: la implementación queda organizada para explicar cada componente y responsabilidad.
